An entry for the [Deadpan Forecasts for Cities That Do Not Exist](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c) bounty on make.fun: one absurd but believable weather line for an invented city, judged by a dry TV meteorologist.

## The entry

> Tonight in Gloombury: overcast with a 90% chance of sideways rain, lows of 4 degrees, and one cloud that has been following the mayor since Tuesday.

## How it works

`main.py` (Python 3, standard library only) writes the forecast to `/output/entry.txt` deterministically: it writes a temporary file in the same directory, atomically replaces the target with `os.replace`, and sets mode 644. Running it twice produces byte-identical output.
